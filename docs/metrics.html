Metrics in Depth

How we measure each model's performance. All metrics are implemented from scratch in metrics.py.

True positives, false positives, false negatives

Precision, recall and F1 are computed per income tier. For one tier (say, Low), every test row falls into one of these:

Predicted LowPredicted not Low
Actually LowTP: true positiveFN: false negative (missed)
Actually not LowFP: false positive (false alarm)true negative
 
def true_positive(y_true, y_pred, target_class):
    tp = 0
    for gt, pred in zip(y_true, y_pred):
        if gt == target_class and pred == target_class:
            tp += 1
    return tp
# false_positive(): gt != target_class and pred == target_class
# false_negative(): gt == target_class and pred != target_class

Accuracy

Accuracy = correct predictions / all predictions × 100%

The simplest measure: the share of test rows whose tier was predicted correctly. It treats every row the same, so a model can score well by being good at the largest tier (Middle, 40% of rows) only.

def accuracy_metric(actual, predicted):
    correct = 0
    for i in range(len(actual)):
        if actual[i] == predicted[i]:
            correct += 1
    return correct / float(len(actual)) * 100.0

Precision

Precision = TP / (TP + FP)

Of the rows the model predicted as this tier, how many really are? High precision means few false alarms.

tp = true_positive(y_true, y_pred, class_idx)
fp = false_positive(y_true, y_pred, class_idx)
precision_dict[class_name] = float(tp) / float(tp + fp)   # 0.0 if tp + fp == 0

Recall

Recall = TP / (TP + FN)

Of the rows that really are this tier, how many did the model find? High recall means few misses.

tp = true_positive(y_true, y_pred, class_idx)
fn = false_negative(y_true, y_pred, class_idx)
recall_dict[class_name] = float(tp) / float(tp + fn)      # 0.0 if tp + fn == 0

F1 score

F1 = 2 × (Precision × Recall) / (Precision + Recall)

The harmonic mean of precision and recall. It is only high when both are high, so a model cannot score well by predicting one tier for everything.

p = precision_dict[class_name]
r = recall_dict[class_name]
f1_dict[class_name] = 2.0 * ((p * r) / (p + r))           # 0.0 if p + r == 0

Weighted mean

Weighted mean = Σ (score of tier × test rows of tier) / all test rows

To get one number per model, the per-tier scores are averaged, weighted by how many test rows each tier has (105 Low, 140 Middle, 105 High).

def get_weighted_mean(scores, counts):
    total = sum(counts.values())
    weighted_sum = sum(scores[tier] * counts[tier] for tier in scores)
    return weighted_sum / float(total)

Note: the weighted mean of recall always equals accuracy (it adds up to correct predictions / all rows), which is why the two columns match in the results. Weighted precision and F1 do add new information.
